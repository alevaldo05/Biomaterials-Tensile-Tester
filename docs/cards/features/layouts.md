# Layouts

Feature card. Update it in the same change as the feature.

## Purpose
Start screen, Sidebar, Cards, Tabs, Reading; they rearrange existing content.

## Files
- `layouts.js`
- `layouts.css`

## What the user sees
- Page arranged to the chosen layout
- Reading: the "On this page" list sits beside the text; when the page area is narrower than 50rem (large text) it goes above the text and the text uses the full width

## Behavior to keep
- Content is written once; layouts only move it
- The skip link moves focus

## Labels that must stay
- "Prototype · hardware untested" in the Sidebar

## Depends on
- Display settings

## How to check
- Open each page in each layout
