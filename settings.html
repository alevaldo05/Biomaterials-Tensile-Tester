Settings

Color theme

Saved in this browser only.

Layout

How pages are arranged.

Font

The typeface for the whole site. These use fonts already on your computer (nothing is downloaded), so they look a little different on Windows, Mac, and other systems.

Style

Shapes and type. With the Green light color theme, each style also uses its own colors; other color themes keep their own colors.

Text size

Scales the page text. It builds on your browser’s own text size and zoom, so it never reduces them. STOP, warnings, and labels stay visible at every size.

Sample: σ = F/A0 · 195 GPa · Draft values, not measured.

Spacing

The space between blocks, table rows, and list items. Buttons, inputs, and focus outlines keep their size.

Motion

The only motion on this site is the fade on buttons and the brief highlight when you jump to a step. Recording and the live graph are not affected.

Graph line thickness

The starting thickness of the curve on the main graph (test pages, Load Test, protocol pages, and Materials). You can still change one graph with its own slider; that is not saved. Downloaded PNG and SVG images use the thickness shown.

Curve style

Whether the curve starts as a plain line or a line with a marker on each plotted point. The labels and key results do not depend on color alone.

Graph grid

The grid behind the curve. Turning it off never removes the axes, tick numbers, or units. Downloaded images show what is visible.

Stress unit

How stress and modulus are written on the main graph pages (test pages, Load Test, protocol pages): readouts, Key results, axis numbers and titles. Modulus is always stress per 1 of strain (a ratio), never per percent. Downloaded CSV files and the numbers in the Excel data sheet always stay in MPa.

Strain unit

Strain as a ratio (mm/mm) or as a percentage, for the readout, the strain axis, the strength and failure strain, and the fitted interval text. Energy density stays in MJ/m³. Downloaded files always keep strain as a ratio.

Displayed digits

How many significant digits are shown on the main graph pages. More displayed digits do not improve measurement accuracy. Downloaded files keep their own precision.

Pre-test checklist

A reminder that appears each time you press Start on a test page, for classes or training. When it is On, Start stays disabled until every item shown is ticked. Items that only apply to tissue are shown for biological materials only. It is a reminder, not a safety certification. It is Off by default and saved in this browser only, so turn it on in each browser that needs it.

The theme, font, layout, style, text size, spacing, motion, graph, unit, and digit choices change appearance only (the unit and digit choices change only how numbers are written on screen and in the printed report and images). The pre-test checklist only adds a reminder before a test starts. These settings are saved in this browser only. None of them change test data, results, or what is sent to the tester, and test data is never saved by the site.
